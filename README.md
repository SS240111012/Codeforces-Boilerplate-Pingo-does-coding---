## Why not use the all in one <bits/stdc.++h> ?

The thing is simple ; If you only want to use the most needed meaning the most common Codeforces STLS, you'd love to call them out instead of the whole crew , since less stls == less queue to let them go in and compile .

Another thing is that since The template uses namespace std instead of std::your_variable_here ;
so If I have 1e18 STLs, a lot of Variables are taken by the Program -- and you don't want that do you ?
